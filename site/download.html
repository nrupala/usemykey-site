Download MyKey

One vault, everywhere. The Android app, the desktop app, and the web app all open the same encrypted vault file.

Android

The full app: fingerprint unlock, passkeys, autofill in other apps and browsers, sign-in codes, change reminders, skins, and two-key backups.

Download the Android app (APK)

Version 1.3.0 · 6.1 MB · SHA-256 a7bd97f808666b3a6beef9b91dfc3c51b094f31f36d4cee7e7724331304ffb70

Open the file on your phone and allow the install when Android asks. This is a direct download from us; a Google Play listing is in preparation. The app asks for no internet permission and works fully offline.

This build is signed with our permanent release key, so future updates install in place. If you ran one of the earlier test builds, Android will ask for one fresh install this time — export your vault file from the old app first (Settings → "Download my vault file"), then open it in this one.

Web app (installable)

The same app runs in a browser and can be installed like a native app. It stores your vault on the device, in the browser, and works offline after the first load.

To install: open this page's app in Chrome or Edge on your phone or computer, then choose Install app (or Add to Home Screen) from the browser menu. On iPhone or iPad, open it in Safari and choose Add to Home Screen from the Share menu.

The hosted web app address will be listed here as the public launch completes. The Android download above is the same code, available now.

Desktop (Windows, macOS, Linux)

The desktop app adds the command line, agent keys for programs you trust, your passkeys on file, and folder sync through your own cloud. Version 2.2.0:

Windows app (17.1 MB)
Windows command-line tool (14.0 MB)
Linux bundle — app + command line (30.6 MB)

SHA-256 checksums for all three files, if you want to check your download arrived intact. On Linux, make the programs executable after unpacking (chmod +x MyKey mykey-cli).

These builds are not code-signed yet, so your system will warn you — that is expected for now. On Windows, SmartScreen says “Windows protected your PC”: choose More info, then Run anyway.

macOS: there is no ready-made Mac download yet. The build script in the project makes a MyKey app when it runs on a Mac; a signed Mac download comes once a signing certificate exists. Source and project page: github.com/nrupala/mykey.

Browser extension

Fill logins in Chrome, Edge, Brave and other Chromium browsers, and in Firefox — straight from your desktop vault. The extension holds no copy of your vault: it talks to the desktop app on your own computer over a private channel you approve, and it makes no internet requests.

Get the extension (project page)

Store listings are on the way. Today the install is a ready-made package from the project page, with plain step-by-step instructions. You need the desktop app above, and there is a one-time pairing you approve on the desktop — that approval is what proves the browser is yours.

Moving from another password app?

Export a CSV file from Chrome, Edge, Firefox, or another password manager, then import it in MyKey. The file is read on your device only — it is never uploaded. See Support & FAQ for the steps.
